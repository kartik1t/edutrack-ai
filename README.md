# EduTrack AI
### Intelligent Student Performance and Academic Management System

EduTrack AI is a web-based academic management system designed to help manage student attendance, marks, assignments, and academic performance in one centralized platform.

## Problem Statement
Academic information is often maintained across separate records, making it difficult to monitor student progress and identify students who may need additional academic support.

## Objectives
- Centralize student academic records.
- Manage attendance and assessment marks.
- Track assignments and academic progress.
- Identify students who may be at academic risk.
- Provide rule-based recommendations to support improvement.

## Planned Features
- Student and faculty authentication
- Student academic dashboard
- Attendance management
- Marks and assignment tracking
- Academic risk classification: Low, Medium, and High
- Performance recommendations

## Proposed Technology Stack
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Java and Spring Boot
- **Database:** MySQL
- **Persistence:** Spring Data JPA and Hibernate
- **Security:** Spring Security and JWT
- **Testing:** Postman
- **Version Control:** Git and GitHub
